# 会话上下文无缝交接 (Handoff Prompt)

本 Skill 专门用于解决会话上下文过长、Token 消耗过大或需要开启新会话时，**一键生成直接可喂给下一个智能体的标准交接话术**。

---

## 触发条件

当用户输入包含以下意图时立即触发本 Skill：
- 显式关键词：`交接`、`交接话术`、`上下文交接`、`移交新会话`
- 上下文转移诉求：“会话太长了，帮我整理个交接发给新会话”、“准备开新窗口，整理一下进度发给下个AI”等。

---

## 输出规范与核心原则

1. **必须直接可复制**：
   - 核心交接内容必须置于一个**独立的代码块（Markdown code block）**中，方便用户一键点击“复制（Copy）”。
2. **高信噪比与关键信息无损**：
   - 剔除调试过程中的弯路、闲聊或冗长过程代码。
   - 保留：**项目背景与核心目标**、**已修改/已确认的关键文件与绝对路径**、**已完成的具体成果与结论**、**关键技术约束与决策**、**当前尚未完成的任务与下一步指令**。
3. **给新智能体的明确引导令（Role & Instruction）**：
   - 交接话术的开头要为接收的新智能体设定好上下文角色，结尾要有清晰明确的“第一步行动引导”。

---

## 交接话术标准模板

智能体在收到“交接”指令后，必须提炼当前会话内容，并严格按照以下结构生成放入代码块中：

````markdown
以下是为您整理的**新会话交接话术**。您可以直接点击代码块右上角的「复制」，在新对话中直接粘贴发送即可无缝续接：

```markdown
【上下文无缝交接指令】
你好！我们刚刚在上一段会话中推进了一项工作，因为上下文较长现切换到新窗口。请你仔细阅读以下总结，并直接接手下一步工作：

### 1. 核心目标 / 项目背景
- [简述当前任务的总体目标、技术栈或业务背景]

### 2. 已完成的关键进展与技术决策
- [列出上一轮对话中已经确认的方案、已经编写/修改的核心文件或已验证的结论]
- 关键路径与文件（如有）：
  - `文件路径1`
  - `文件路径2`

### 3. 当前任务进度与遗留待办 (TODO)
- [清楚写明目前任务停留在哪一步，还有哪些待办事项]
- [如有遇到的报错/已知坑点/特殊限制，务必写明]

### 4. 下一步具体行动指令
- 接手后，请首先进行：[明确指出新智能体第一步需要做什么，期望给出什么结果]。
```
````

---

## 执行流程

1. **审视全对话**：快速扫描本会话从头到尾的真实工作进展，提取有效事实、代码/文件变更以及技术决策。
2. **提炼四个关键维度**：
   - **目标**：用户最终想达成什么？
   - **产出**：已经产出了什么？修改了哪些关键代码/配置？
   - **停滞点**：现在进行到了哪里？遇到了什么问题/未尽事宜？
   - **接力棒**：下一个智能体第一句话应该干什么？
3. **输出**：在单独代码块中输出交接内容，简洁清晰，不添加多余赘述。
